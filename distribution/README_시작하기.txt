YU Fluid · 적응형 결과 / 통합 CFD 웹앱

1. ZIP을 전체 압축 해제한 뒤 index.html을 열면 기존 흰색 웹앱과 같은 첫 화면이 나옵니다.
   결과 보기에서는 검증된 적응형 결과를, 3D 화면에서는 실제 계산 메시를 볼 수 있습니다.
   이전 기준선 3D 결과는 중복 포함하지 않았습니다. 원래 패키지에 별도로 보존됩니다.
2. 파일로 연 계산하기 화면에는 CAD 업로드와 변수·메시 선택 UI가 보입니다.
   파일만 연 상태에서 새 CAD 검증이나 OpenFOAM 계산은 동작하지 않습니다.
3. 실제 계산을 하려면 Python 3.12 이상과 Docker Desktop을 설치하고 Docker가 실행 중인지 확인하세요.
   Mac에서는 run_mac.command, Windows에서는 run_windows.cmd를 실행하세요.
   첫 실행은 CAD/VTK 등 Python 의존성을 설치하므로 인터넷 연결이 필요할 수 있습니다.
   서버 주소 http://127.0.0.1:8765/ 에서 계산하기를 누르면 CAD 확인·운전조건·
   70만/80만급 메시 선택·확인·실제 진행 로그·후처리·결과 보기가 동작합니다.
4. 새 CFD 실행은 최소 55 GiB의 여유공간이 필요합니다. 현재 업로드 계산은
   23셀 5-4-5-4-5 탱크 계열의 영역별 STEP 3개와 원형 상하 포트에 한합니다.
   임의 CAD/STL 전체 자동 해석이나 다른 냉각수 물성은 지원하지 않습니다.
5. 배포본은 기존 결과의 41 GiB 필드 전체가 아니라 실제 검증 보고서와
   원본 로그 마지막 512 KiB, 적응형 뷰어 데이터를 담습니다. 검증 경고:
   과도 1,800 시간단계 중 32개는 목표 에너지 잔차 도달 전에 결합 반복 상한에
   닿았습니다. 단일 메시 결과는 격자 독립성/교차 검증 전 검토용입니다.

Mac/Windows 실제 새 CAD 전체 CFD 완료 여부는 배포받는 환경에서 별도 검증이 필요합니다.
