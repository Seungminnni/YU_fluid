# Full-transient dynamic thermal plan

## 계산 경로 선택

현재 결과의 `frozen-flow`는 정상 유동장을 먼저 수렴시킨 다음 매 1초마다
유체·고체 에너지 방정식을 푼다. 다음 조건을 모두 유지할 때만 이 경로를 쓴다.

- 냉각수 밀도·점도·비열·열전도도가 상수다.
- 중력이 0이며 부력을 사용하지 않는다.
- 발열원이 운동량·난류 방정식에 직접 결합되지 않는다.

이 조건에서는 `q'''(t,SOC,T)`가 바뀌어도 온도만 바뀌며 수렴된 `U(x)`는
변하지 않는다. 따라서 동적 UDF라는 이유만으로 속도를 매번 다시 푸는 것은
필수가 아니다.

냉각수 밀도·점도의 온도 의존성, Boussinesq/부력, 자연대류, 온도에 따른 유량
또는 다른 열-운동량 피드백을 사용하면 `full-transient`를 선택한다. 열전도도와
비열만 온도에 의존할 때는 에너지 방정식의 비선형 반복이 필요하지만 운동량
재계산은 필수가 아니다. full-transient 경로는 각
내부 시간 단계에서 PIMPLE outer correction을 수행해 `U`, `p_rgh`, `k`,
`omega`, 유체 `h`, 고체 `h`를 함께 갱신한다.

## UDF 적용 계약

예정된 물리 기반 소스의 계산 순서는 다음과 같다.

```text
physical time → current and SOC → Ri(SOC,T), ΔS(SOC,T)
              → cell heat q [W] → volumetric source q''' [W/m³]
```

소스 구현 전에는 사용할 셀의 용량·SOC 초기값·방전 종료 조건·저항/엔트로피
상관식의 적용 범위와 부호를 확정해야 한다. 생성된 UDF에는 입력 해시와 식의
출처를 기록하고 다음 gate를 통과시킨다.

1. SOC가 0–1 범위를 벗어나지 않는다.
2. `Ri`, `ΔS`, `q`, `q'''`의 단위와 부호를 독립 계산으로 대조한다.
3. 23개 셀에서 `∫q'''dV`가 의도한 총 발열과 일치한다.
4. 상수 `q'''=16,325 W/m³`를 넣었을 때 현재 기준 결과를 재현한다.
5. 에너지 불균형, 질량 불균형, 온도 범위 및 모니터 값이 허용치 안이다.

## 시간 단계와 출력 간격

브라우저의 1초 프레임과 solver `deltaT`는 같은 개념이 아니다. full-transient
계산은 Courant/Diffusion 제한에 맞춰 1초 안에서 여러 작은 내부 시간 단계를
계산한 뒤, 정수 초에 필드와 모니터를 저장한다.

2026-09-10 표준 메시 pilot의 측정값은 다음과 같다.

| 항목 | 측정값 |
| --- | ---: |
| 도달 물리 시간 | 0.73624309 s |
| adaptive time steps | 215 |
| PIMPLE outer corrections | 645 |
| 안정화된 `deltaT` (`maxCo=5`) | 약 0.003425414 s |
| 마지막 wall time | 197 s |
| clean solver end | 아니요, 계획 중단 |

이 짧은 구간의 선형 외삽은 1,800초에 약 525,484 time steps와 1,576,452
outer corrections, 약 5.6일이다. 이는 예산 추정일 뿐 완료시간 보장은 아니다.

## 실행 승인 순서

1. 상수 발열로 1초 `deltaT`/`deltaT/2` pilot을 비교한다.
2. 선택한 동적 UDF로 1초를 재검증한다.
3. 10초, 60초 순으로 늘려 발산·Courant·에너지/질량 균형과 모니터 안정성을 본다.
4. 각 단계가 통과한 뒤에만 1,800초 계산을 시작한다.
5. 뷰어의 수렴 그래프는 누적 PIMPLE outer iteration을 x축으로 쓰고 각 방정식의
   raw OpenFOAM initial residual을 표시한다. Fluent의 scaled residual로 이름을
   바꾸거나 수치를 임의 변환하지 않는다.

중단된 대형 MPI 필드는 결과가 아니므로 보존하지 않는다. 위 측정 사실과
검증 보고서만 남기고, 최종 승인된 계산의 원본 필드·모니터·로그만 보존한다.
