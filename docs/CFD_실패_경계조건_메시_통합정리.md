# YU_fluid CFD 실패·배제 조건 통합 기록

작성일: 2026-09-30
대상: Ø28, Ø31, Ø34 물 조건 시험과 기존 프레임워크의 관련 실패 사례

## 1. 이 문서에서 말하는 “실패”의 뜻

여기서 **실패**는 해당 조합이 정해진 검증 기준을 통과하지 못했다는 뜻이다. 물리적으로 영구히 불가능하다는 뜻은 아니다. 같은 이름의 설정이라도 CAD, OpenFOAM 버전, 격자 크기, 벽면층, 수치기법이 달라지면 결과가 달라질 수 있다.

판정은 다음처럼 구분한다.

- **메시 실패**: 셀 수, 육면체 비율, `checkMesh`, 층 생성, 영역·계면 검사 중 하나 이상 실패
- **유동 검증 실패**: 메시를 통과했지만 y+, 최근 200회 잔차, 질량보존, 압력강하 안정성 또는 필드 안전성 기준 실패
- **운영 실패**: Docker 연결 종료, 작업 프로세스 종료 등으로 설정 자체의 성패를 판정할 수 없음
- **사용자 중단**: 계산 완료 전에 중단되어 판정할 수 없음

이 구분이 필요한 이유는 운영 중단이나 미완료 작업을 “나쁜 메시 설정”으로 잘못 결론 내리지 않기 위해서다.

## 2. 공통 물리 조건과 합격 기준

Ø28·Ø31·Ø34 비교 시험에는 다음 물 조건을 유지했다.

| 항목 | 값 |
| --- | ---: |
| 냉각수 | 탈이온수 |
| 입구 온도 | 293 K |
| 입구 속도 | 0.4 m/s |
| 출구 압력 입력 | 101,325 Pa |
| 배터리 수 | 23개 |
| 메시 생성 병렬 수 | 1 rank |
| M5 Pro 솔버 병렬 수 | 12 ranks |

600k 계열 A/B 시험의 주요 기준은 다음과 같다.

| 검증 항목 | 기준 |
| --- | ---: |
| 총 셀 수 | 600,000~690,000 |
| 육면체 비율 | 88% 이상 |
| 최대 비직교도 | 70° 이하 |
| 최대 skewness | 5 이하 |

| 최근 200회 필수 유동 잔차 | 각 `1×10⁻⁴` 이하 |

### 출구 역류 진단

기존 출구 속도 경계는 `inletOutlet`이며 역류 시 `inletValue uniform (0 0 0)`을 사용했다. 같은 방식으로 재구성한 비교는 다음과 같다.

| 시안 | 출구 면 수 | 역류 면 수 | 역류량/순 출구 유량 | 역류 면 중 속도 0인 면 |
| --- | ---: | ---: | ---: | ---: |
| Ø28 | 992 | 0 | 0% | 0 |
| Ø31 | 1,212 | 41 | 0.1515% | 41 |
| Ø34 | 1,447 | 105 | 0.4876% | 105 |

Ø34의 역류가 Ø28·Ø31보다 큰 것은 분명하고 압력 정체의 유력한 기여 요인이다. 다만 `pressureInletOutletVelocity`로 바꾼 시험의 압력 잔차가 `4.7806×10⁻⁴`였으므로 **역류 경계조건 하나가 유일한 원인이라고 단정할 수 없다**. 현재 근거는 출구 부근 재순환, 국부 메시, 압력-속도 결합이 함께 영향을 준다는 쪽에 가깝다.

## 8. Ø34 800k 이상 메시 시험

셀 수를 800k 이상으로 늘리면 압력 잔차가 해결되는지 확인하려 했으나, 두 시험 모두 솔버 전에 메시 품질 단계에서 멈췄다.

| 실행 ID | 메시 프로필 | 실제 셀 수 | 실패 내용 | 판정 |
| --- | --- | ---: | --- | --- |
| `d61e68e26fde4f3d9886bff6ad65d410` | `production_frame_fit_800k_6um_11layers_motion` | 935,507 | 허용 상한 920,000 초과; `checkMesh` 1개 검사 실패; snappy 최종 진단에 face twist 불량 12면 | 솔버 미실행 |
| `de854e8a717e49fdb58611009fd161b0` | 위 설정에서 포트 refinement cap을 level 1로 축소 | 920,006 | 상한을 6셀 초과; face twist 불량 12면이 남아 `checkMesh` 실패 | 솔버 미실행 |
| `2b56109d0640452095f4a72848f8e9e2` | 3.00 mm 배경격자 + 포트 level 1 | 미완료 | 메시 생성 중 사용자 요청으로 중단 | 판정 불가; 실패 설정으로 분류하지 않음 |

불량 face twist는 포트 림 부근의 국부 형상·격자 결합 문제로 진단됐다. 따라서 “전체 셀 수만 800k 이상으로 증가”하는 방법은 해결책으로 확인되지 않았다. 포트 림의 표면 분할, 국부 refinement 전이, feature 처리 또는 출구 유동영역 길이를 함께 바꾸지 않으면 같은 결함이 남을 가능성이 크다.

기존 프레임워크에서는 배경격자 2.90 mm·첫 층 12 µm로 849,284셀 메시와 냉간 유동을 통과한 사례가 있다. 이것은 다른 CAD와 당시 90% 육면체 기준의 결과이므로 Ø34에 설정값만 복사해 성공을 보장할 수 없다.

## 11. 현재 근거로 배제하거나 단독 해결책으로 쓰지 말아야 할 조합

- Ø34에서 6 µm·10층 또는 4 µm·10층: 층 생성 자체가 무너짐
- Ø34에서 6 µm·12층: 11층보다 y+가 악화됨
- `pressure_limited_0p5`: 압력과 U 잔차가 모두 악화됨
- `pressure_reltol_zero` 단독 적용: 압력 잔차 개선이 약 0.25%에 불과함
- 출구 `pressureInletOutletVelocity` 단독 적용: 역류 처리는 달라졌지만 압력 잔차는 개선되지 않음
- 압력 완화계수 0.15: 176회에서 음의 온도로 발산
- 포트 refinement만 level 2→1로 낮춘 800k 메시: face twist 12면이 그대로 남음
- 총 셀 수만 늘리는 접근: Ø34에서는 메시 품질을 먼저 실패해 효과를 검증하지 못함

압력 완화계수 0.5와 출구 역류 대응 조합은 완전히 배제할 설정은 아니다. 지금까지 가장 낮은 Ø34 압력 잔차를 만들었지만 기준은 통과하지 못했으므로, 새로운 형상·출구 영역·국부 메시 개선과 결합할 때만 비교 기준으로 재사용하는 편이 타당하다.

## 12. 새 CAD 또는 새 물성 실험에 적용할 원칙

1. CAD, 메시, 벽면층, 경계조건, 수치 설정 중 한 번에 한 축만 바꾼다.
2. 실패 작업의 유동장과 메시를 다음 시도의 초기장으로 사용하지 않는다. 진단과 고정 입력만 보존하고 새 UUID에서 새 CAD·메시로 시작한다.
3. 메시 합격 뒤 실제 `nSurfaceLayers` 좌표 분포와 y+ 좌표 분포를 같은 면에서 비교한다. 평균 층수만으로 판정하지 않는다.
4. 새 냉각수에서는 점도·밀도 변화로 y+가 달라지므로 물에서 통과한 첫 층 높이를 자동 승인하지 않는다.
5. 출구 역류가 있으면 역류 면적·질량비·속도와 압력 잔차를 같이 기록한다. 역류 유무만으로 수렴 실패 원인을 단정하지 않는다.
6. 800k 이상 메시를 만들 때는 전체 셀 수보다 포트 림의 face twist와 refinement 전이를 먼저 해결한다.
7. 메시, y+, 최근 200회 잔차, 질량보존, 압력강하, 온도·속도 안전성을 모두 통과하기 전에는 웹앱 결과로 게시하지 않는다.
